## Logs & exponents

*Details: [Topic 0](topics/00-math-toolkit.mdx)*

| | |
|---|---|
| $\log_b x = y \iff b^y = x$ | $\log_b(xy) = \log_b x + \log_b y$ |
| $\log_b(x/y) = \log_b x - \log_b y$ | $\log_b x^a = a\log_b x$ |

## Proof templates

*Details: [Topic 2](topics/02-proof-techniques.mdx), [Topic 3](topics/03-correctness.mdx)*

- **Induction:** base case → hypothesis $S(k)$ → prove $S(k+1)$ by writing it as "$S(k)$ + new piece".
- **Contradiction:** assume the opposite → derive something impossible → so the claim holds.
- **Contraposition:** to prove $P \Rightarrow Q$, prove $\neg Q \Rightarrow \neg P$.
- **Loop invariant:** Initialization · Maintenance · Termination (substitute the exit value, e.g. $i = n + 1$).
- **Correctness** = partial correctness + termination.

## Algorithms

*Details: [Topic 4](topics/04-insertion-sort.mdx), [Topic 7](topics/07-divide-and-conquer.mdx)*

| | Best | Worst | Extra space | Stable |
|---|---|---|---|---|
| Insertion sort | $\Theta(n)$ sorted | $\Theta(n^2)$ reverse | $\Theta(1)$ | yes |
| Merge sort | $\Theta(n\log n)$ | $\Theta(n\log n)$ | $\Theta(n)$ | yes |
| Binary search | $\Theta(1)$ | $\Theta(\log n)$ | $\Theta(1)$ iterative | — |

- Insertion sort worst case: shifts $= \frac{n(n-1)}{2}$. Shifts = number of inversions.
- Merging lists of sizes $p$ and $q$: at most $p + q - 1$ comparisons.

## Asymptotics

*Details: [Topic 6](topics/06-asymptotic-notation.mdx)*

- $f = O(g)$: $\exists c, n_0$ with $f(n) \le c\,g(n)$ for all $n \ge n_0$
- $f = \Omega(g)$: $\exists c, n_0$ with $f(n) \ge c\,g(n)$ for all $n \ge n_0$
- $f = \Theta(g)$: both, i.e. $c_1 g \le f \le c_2 g$
- $1 < \log n < \sqrt n < n < n\log n < n^2 < n^3 < 2^n < n! < n^n$
- Disprove $f = O(g)$: assume $c, n_0$ exist, derive $n \le$ constant, contradiction.

## Recurrences

*Details: [Topic 8](topics/08-recurrences.mdx)*

For $T(n) = aT(n/b) + f(n)$: level $i$ has $a^i$ nodes of size $n/b^i$, there are $\log_b n + 1$ levels, and the leaves number $n^{\log_b a}$.

| Recurrence | Θ |
|---|---|
| $T(n/2) + 1$ | $\log n$ |
| $T(n/2) + n$ | $n$ |
| $2T(n/2) + 1$ | $n$ |
| $2T(n/2) + n$ | $n\log n$ |
| $2T(n/2) + n^2$ | $n^2$ |
| $4T(n/2) + n$ | $n^2$ |
| $T(n-1) + 1$ | $n$ |
| $T(n-1) + n$ | $n^2$ |

## Master method

*Details: [Topic 9](topics/09-master-method.mdx)*

For $T(n) = aT(n/b) + f(n)$, compare $f(n)$ with the watershed $n^{\log_b a}$:

| Case | $f(n)$ is… | $T(n)$ |
|---|---|---|
| 1 | $O(n^{\log_b a - \varepsilon})$: polynomially smaller | $\Theta(n^{\log_b a})$ |
| 2 | $\Theta(n^{\log_b a}\lg^k n)$, $k \ge 0$ | $\Theta(n^{\log_b a}\lg^{k+1} n)$ |
| 3 | $\Omega(n^{\log_b a + \varepsilon})$ **and** $af(n/b) \le cf(n)$, $c < 1$ | $\Theta(f(n))$ |

- Iteration: $a^{\log_b n} = n^{\log_b a}$; $3T(n/4) + n = 4n - 3n^{\log_4 3} = \Theta(n)$.
- Not covered by the theorem: $T(n-1)$, uneven splits, $f = n/\lg n$.

## Quicksort & selection

*Details: [Topic 10](topics/10-quicksort-and-selection.mdx)*

- Partition (pivot $= A[r]$): $n - 1$ comparisons; invariant `A[p..i]` $\le x$ < `A[i+1..j−1]`.
- Quicksort: worst $\Theta(n^2)$ (sorted input), best and average $\Theta(n\log n)$; any constant-ratio split is $\Theta(n\log n)$. In place, not stable.
- Randomized-Select: expected $\Theta(n)$, worst $\Theta(n^2)$. Median of medians: worst $\Theta(n)$ via $T(n/5) + T(3n/4) + \Theta(n)$.
- Nuts & bolts: partition nuts with a bolt, then bolts with the matching nut, $\Theta(n\log n)$ expected.

## Maximum subarray

*Details: [Topic 11](topics/11-maximum-subarray.mdx)*

- Brute force $\Theta(n^2)$; D&C best of left / right / crossing, $T(n) = 2T(n/2) + \Theta(n) = \Theta(n\log n)$.
- Crossing: sweep left from $mid$ and right from $mid+1$, each sum starting at $-\infty$.
