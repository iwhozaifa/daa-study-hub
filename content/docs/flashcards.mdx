## Study in Anki instead

The cards above come from one file, [`flashcards/daa-flashcards.csv`](https://github.com/iwhozaifa/daa-study-hub/raw/main/flashcards/daa-flashcards.csv).
Anki imports that same file and adds spaced repetition, so it shows each card again just before you would forget it.

1. Download the CSV from the link above.
2. In Anki, go to **File → Import** and pick the CSV. The `#…` lines at the top already set the separator, columns and tags.
3. To drill one topic, search the deck for its tag, for example `tag:t4`.
