## How to use a topic page

Every topic page offers **four study modes as tabs**. Pick the one that suits you today. If it isn't
clicking, switch to a different tab rather than re-reading the same one.

| Mode | Use it when… |
|---|---|
| **Visual** | you want to *see* it: trace tables, diagrams, step-by-step pictures |
| **Worked example** | you want one concrete problem solved slowly, then the rule |
| **Guided questions** | you want to figure it out yourself with hints (answers are hidden) |
| **Explanation & drill** | you want a straight explanation, then practice problems |

The site remembers the tab you choose (pick "Visual" once and every page opens on Visual).

Every topic ends with a **Mastery check**: a fresh problem to solve *without* hints. A topic is
done only when you can solve it **and** explain it in your own words.
