# Contributing

Classmates can fix mistakes, add practice questions or improve explanations through a GitHub pull request.

The three rules, in short:

1. **Write it yourself.** Never paste text, figures or examples from the slides or the book. Explain in your own words
   with your own numbers, and cite *"Slide N, deck"* or *"CLRS 4e §X"*. Never commit PDFs.
2. **No full assignment solutions.** Hints, analogies and new practice problems only.
3. **Match the topic page template** and make sure `mkdocs build --strict` passes.

The full guide, including the exact commands, is in
[CONTRIBUTING.md on GitHub](https://github.com/iwhozaifa/daa-study-hub/blob/main/CONTRIBUTING.md).
